## Technical Specifications

### File Formats
- **PNG** for all UI elements, icons, and images with transparency
- **JPG** for large background images
- **SVG** for simple icons and logos (optional, for scalability)

### Resolution Guidelines
- All images should be created at 2x resolution for retina displays
- Icons should be square with consistent padding
- Backgrounds should be seamless or have fade-to-black edges
- All images should include appropriate glow effects and cyberpunk aesthetic

### Color Palette
- **Primary**: #FF2DAA (Neon Pink)
- **Secondary**: #22E3FF (Electric Blue)
- **Accent**: #FFDB6E (Golden Yellow)
- **Success**: #3CE3C5 (Mint Green)
- **Mystical**: #C9A0FF (Mystical Purple)
- **Background**: #0E0E12 (Dark Purple-Black)
- **Text**: #FFFFFF (White)
- **Text Dim**: #AAAAAA (Gray)

### Animation Guidelines
- Spell effects should have 8-12 frames for smooth animation
- UI elements should have hover, active, and disabled states
- Achievement effects should be celebratory with particle elements
- Loading animations should be subtle but engaging

### Accessibility Considerations
- All icons should have high contrast versions
- Important UI elements should be distinguishable without color
- Text should remain readable on all backgrounds
- Consider color-blind friendly alternatives for key elements

## Priority Order

1. **High Priority**: App icons, basic UI elements, main backgrounds
2. **Medium Priority**: Workstation icons, ingredient icons, achievement icons
3. **Low Priority**: Character sprites, advanced effects, coven system images

This comprehensive image requirements list should guide the creation of all visual assets for the Cyber Witches game, ensuring a consistent cyberpunk aesthetic across all elements.
