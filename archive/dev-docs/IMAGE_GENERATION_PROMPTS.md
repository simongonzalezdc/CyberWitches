# Image Generation Prompts for Cyber Witches: Idle Coven

This document contains detailed prompts for generating 15 retro pixel art images that match the game's cyberpunk aesthetic and color scheme.

## IMPORTANT: Standard Image Size

**ALL images should be generated at 2048x2048 pixels (square format).**

After generation, images will be cropped/resized to their final display sizes. This standardized approach makes generation easier and allows flexible cropping for different aspect ratios.

## Color Palette Reference
- **Primary Pink**: #FF2DAA (neon pink)
- **Secondary Cyan**: #22E3FF (electric blue)
- **Accent Yellow**: #FFDB6E (golden yellow)
- **Success Green**: #3CE3C5 (mint green)
- **Background Dark**: #0A0A0F, #1A1A2A, #1F1F3A
- **Text**: #FFFFFF (white)

## General Style Guidelines for All Images

1. **Generate Size**: ALL images should be generated at **2048x2048 pixels (square format)**
2. **Pixel Art Style**: True 8-bit pixel art - no anti-aliasing, clear pixel edges, limited color palette
3. **Color Usage**: Stick to the specified hex colors exactly (#FF2DAA, #22E3FF, #FFDB6E, #3CE3C5)
4. **Background**: Use dark backgrounds (#0A0A0F, #1A1A2A, #1F1F3A) with transparency where appropriate
5. **Glow Effects**: Use subtle neon glows typical of cyberpunk aesthetic
6. **Consistency**: All images should feel like they belong to the same game world
7. **Composition**: Design with the final crop in mind - keep important elements centered
8. **Transparency**: Use PNG format with alpha channel where backgrounds should be transparent
9. **Theme**: Cyberpunk meets magic - high tech with mystical elements

## Post-Generation Processing

After generating all images at 2048x2048px:

1. **Crop to Final Size**: Each image needs to be cropped to its final display size (see table below)
2. **Optimize**: Optimize images for web use while maintaining quality
3. **Verify**: Ensure transparency works correctly for icons and UI elements
4. **Test Tiling**: For tileable patterns, verify seamless tiling works
