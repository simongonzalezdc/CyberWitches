# Meditation Background - Improved AI Image Generation Prompt

## Problem
The current meditation background is too distracting for a focused meditation/tower defense experience. We need a more subtle, calming background that doesn't compete with gameplay elements.

## New Prompt for AI Image Generator

**File**: `images/meditation/meditation-canvas-bg.png`  
**Generate Size**: 2048x2048px  
**Final Display Size**: 1200x800px (3:2 crop)  
**Style**: Retro pixel art, minimal and subtle

**Prompt**:
```
Retro pixel art background scene, 2048x2048 pixels, 8-bit style. A very subtle and minimal cyberpunk meditation space: extremely soft, barely visible geometric patterns in the background, subtle gradient from dark (#0A0A0F) to slightly lighter dark (#1A1A2A), with only the faintest hints of mint green (#3CE3C5) energy wisps that are almost imperceptible. The scene should be extremely minimal - no floating platforms, no bright energy streams, no distracting elements. Just a calm, dark space with the most subtle of mystical atmosphere. Use mint green (#3CE3C5) at only 10-15% opacity for any energy effects. The background should be so subtle it's almost just a dark gradient with the slightest texture. Pixel art style with clear pixel edges, no anti-aliasing. The atmosphere should be peaceful, minimal, and non-distracting - perfect for focusing on tower defense gameplay. Design the composition so it works well when cropped to 3:2 aspect ratio (landscape). The image should feel like a calm void with just the slightest hint of mystical energy, not a busy scene.
```

**Key Changes from Original**:
- Removed: floating platforms, bright energy streams, glowing circles, defensive tower foundations
- Added: emphasis on minimalism, subtlety, barely visible elements
- Changed: mint green opacity reduced to 10-15% (was primary color)
- Focus: calm void with subtle texture, not a busy scene

**Alternative Shorter Prompt** (if the above is too long):
```
Minimal retro pixel art meditation background, 2048x2048 pixels, 8-bit style. Extremely subtle dark gradient from #0A0A0F to #1A1A2A with barely visible mint green (#3CE3C5) energy wisps at 10% opacity. Very minimal - almost just a calm dark void with the slightest mystical texture. No distracting elements, platforms, or bright effects. Pixel art, clear pixel edges, no anti-aliasing. Peaceful and non-distracting for tower defense gameplay. Works when cropped to 3:2 landscape.
```

## Design Philosophy

The meditation background should:
1. **Be minimal** - Almost just a dark gradient with subtle texture
2. **Not compete** - Should fade into the background, not draw attention
3. **Support gameplay** - Tower defense elements should be clearly visible
4. **Feel calm** - Peaceful void-like atmosphere
5. **Be subtle** - Any mystical elements should be barely perceptible

The overlay (now increased to 70% opacity) will further dim the background, making it even less distracting while still providing visual interest.
