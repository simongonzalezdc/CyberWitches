# 🚀 Quick Start Guide

## Get Started in 3 Steps

### 1. Open in Browser

The easiest way to run the game:

```bash
# Option 1: Using npm (if you have Node.js)
npm install
npm start

# Option 2: Using Python
python3 -m http.server 8080

# Option 3: Just open index.html directly
# (Double-click index.html or open in browser)
```

### 2. Play the Game

1. Click **✨ Cast** to gather ingredients
2. Go to **🏭 Workstations** tab
3. Craft your first workstation
4. Watch resources auto-produce!

### 3. Explore Features

- **📜 Inscriptions** - Buy permanent upgrades
- **🔬 Experiment** - Discover hidden recipes
- **📅 Dailies** - Complete daily challenges
- **⭐ Boons** - Unlock prestige bonuses
- **⚡ Ascend** - Prestige for permanent power

## 🎮 Gameplay Loop

1. **Cast** → Gather basic ingredients
2. **Craft Workstations** → Auto-produce resources
3. **Buy Upgrades** → Boost production
4. **Experiment** → Discover new recipes
5. **Complete Dailies** → Earn bonus rewards
6. **Ascend** → Prestige for Eldritch Keys
7. **Buy Boons** → Permanent upgrades
8. **Repeat** → Get stronger each run!

## 💡 Tips

- Workstations auto-produce resources every second
- Experiment when you have lots of ingredients
- Daily tasks reset every day at midnight
- Prestige when you can't progress further
- Eldritch Keys persist across prestiges

## 🐛 Troubleshooting

**Game not loading?**
- Check browser console (F12) for errors
- Try a different browser (Chrome, Firefox, Edge)
- Make sure JavaScript is enabled

**Save not working?**
- Check if localStorage is enabled
- Try clearing browser cache
- Some private browsing modes disable saves

**Performance slow?**
- Close other browser tabs
- Reduce browser extensions
- Game runs at 10 ticks/second (should be fine!)

## 📱 Mobile Play

The game works on mobile browsers too! Just open the URL on your phone.
