# 📤 How to Share with a Friend

## Quick Answer

### Step 1: Build & Package
```bash
npm run build:prod
cd dist
zip -r ../cyber-witches-game.zip .
```

### Step 2: Send the ZIP
Send `cyber-witches-game.zip` to your friend (email, Dropbox, etc.)

### Step 3: Your Friend Runs It
1. Extract ZIP
2. Double-click `start-server.bat` (Windows) or `start-server.sh` (Mac/Linux)
3. Open browser to `http://localhost:8000`

---

## Even Easier: Use the Script

**Mac/Linux:**
```bash
bash package-for-friend.sh
```

**Windows:**
Double-click `package-for-friend.bat`

This does everything automatically and creates `cyber-witches-game.zip` ready to send!
